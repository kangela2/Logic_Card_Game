# Logic_Card_Game 
**Card_Class Edition**

This is a multiplayer card game you play in teams of 2 with 4 people total. This is a game of educated guesses. 

In this iteration of Logic, the game is designed for a single player competing against bot opponents, with a bot partner. The player can infer remaining opponent cards based on knowledge of their own hand, viewing any one of their partner's cards, and any opponent cards revealed during gameplay. Be careful, incorrect guesses allow opposing team bots to reveal any one of your or your partner's cards!

Logic is written in Python and utilizes the PyGame library.

## Running Logic
To play Logic, the user must have Python and [Pygame](https://www.pygame.org/wiki/GettingStarted) installed on their commputer. After running the following script in the Terminal:

```python3 logic.py```

The Logic game window will appear. The user should ensure both the game window and terminal are visible to play the game properly and utilize all the features.
